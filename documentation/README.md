# Portfolio Agent Documentation

This directory stores durable operational records produced by the portfolio agent system. Agent behavior belongs in `AGENTS.md` and `agents/`; operational state and history belong here.

## Files
- `PROJECT_PROPOSAL.md` — current substantial initiative proposal and owner approval state.
- `PROJECT_PLAN.md` — current approved or proposed execution plan and completion criteria.
- `STATUS.md` — concise current state, active phase, blockers, and next role/action.
- `ACTIVITY_LOG.md` — chronological record of meaningful agent work, decisions, handoffs, verification, failures, and approvals.
- `LESSONS_LEARNED.md` — proven lessons from actual portfolio work that may justify future process, skill, or agent improvements.

Do not put portfolio-project deliverables such as data dictionaries, data-quality logs, dashboard documentation, or project-specific technical documentation here. Keep those with the relevant portfolio project or its own documentation area.

Security is the first priority. Never record secrets, credentials, tokens, or sensitive private information in these documents.
