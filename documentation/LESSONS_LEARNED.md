# Lessons Learned

This file records proven lessons from actual portfolio work. Lessons should be understandable to the owner and useful to future agents.

## Current lessons
- Keep the owner involved in initial planning and consequential decisions.
- Treat project-proposal approval and project-plan approval as separate checkpoints.
- Have the Advisor walk the owner through planning documents rather than relying on document-only review.
- Keep agent instructions separate from agent-produced operational documentation.
- Keep portfolio-project deliverables with their relevant project instead of mixing them into agent operational records.
- Security should be the first priority across every agent and reusable skill.

Add new lessons when repeated experience or a meaningful outcome supports them. Do not turn one-off preferences into permanent rules without justification and owner approval where governance changes are involved.
