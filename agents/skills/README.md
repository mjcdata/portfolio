# Agent Skills

This directory is reserved for reusable portfolio-agent capabilities.

A skill should describe a repeatable process that benefits from durable instructions, such as project integration, responsive QA, accessibility review, metadata auditing, or another recurring workflow.

**Security is the first priority for every skill.** Every skill inherits root `AGENTS.md` and must include security considerations appropriate to its capability.

Do not create a skill for a one-off task. Prefer existing role instructions when they already cover the responsibility.

Adding a skill that introduces a new tool, integration, permission, automation, or material workflow change requires owner approval.
